# VoxFlow — Нативний ШІ-асистент голосового вводу та перекладу (C# / .NET 8 WPF)

**VoxFlow** — надлегкий нативний десктопний додаток-оверлей для Windows (написаний з нуля на **C# / .NET 8 WPF + Win32 API** без Electron/Chromium), який перетворює ваше мовлення на чистий текст наживо за допомогою **Google Gemini Live API (`gemini-3.5-transcribe-live`)** та миттєво вставляє його у будь-яку програму (Discord, Telegram, браузер, IDE, документи).

---

## 🚀 Головні переваги нативної версії VoxFlow 2.0

- **Мінімальне споживання ресурсів**: Повна відмова від Electron (Chromium). Замість ~300 МБ оперативної пам'яті та ~245 МБ на диску нативний додаток займає лічені мегабайти та споживає у 6–8 разів менше ОЗП.
- **Плаваючий візуальний індикатор у стилі Whisper (HUD Pill)**: Компактна напівпрозора капсула внизу екрана з живою 8-смуговою звуковою хвилею, прев'ю слів та таймером запису, яка ніколи не перехоплює фокус клавіатури (`WS_EX_NOACTIVATE`).
- **Надійна Автовставка (`Direct Paste`)**:
  - Автоматично відстежує останнє активне зовнішнє вікно (`Discord`, `Telegram`, браузер тощо) та показує поточну ціль (`↳ Discord`).
  - Якщо ви натиснули кнопку «Стоп» мишкою у вікні `VoxFlow`, додаток сам повертає фокус у цільове поле вводу (`AttachThreadInput` + `SetForegroundWindow`), програмно відпускає затиснуті клавіші-модифікатори (`Shift`, `Alt`, `Ctrl`) і виконує чистий `Ctrl+V` через Win32 `SendInput`.
- **Покращене сприйняття української мови (`Voice Boost` + Мовний замок)**:
  - Вбудований DSP-препроцесор звуку: фільтр низьких частот **High-Pass 85 Гц** (прибирає гул мікрофона та дихання), динамічна нормалізація гучності (**Soft AGC**) для чіткого розпізнавання тихих закінчень українських слів та **Pre-Roll буфер (400 мс)**, щоб перші склади ніколи не обрізалися.
  - Жорстке блокування польської та російської мов у системному промпті та клієнтському фільтрі `FilterLanguageLock`.
- **Незалежні від розкладки глобальні Хоткеї (`WH_KEYBOARD_LL`)**:
  - Працюють через фізичні віртуальні коди клавіш (`VirtualKey`), тому комбінації на кшталт `Ctrl+Shift+R` працюють однаково стабільно як на англійській (`ENG`), так і на українській (`УКР`) розкладці.
  - Підтримка режимів **Toggle** (натиснути Старт / Стоп) та **Push-to-Talk** (утримувати клавішу під час мовлення).
- **Зручні вкладки Налаштувань**: Вікно автоматично розширюється при відкритті налаштувань і поділене на 3 логічні вкладки (`⚙️ Загальні`, `⌨️ Хоткеї та Вставка`, `🎙️ Аудіо та ШІ`).

## 📦 Запуск та збірка

### Готовий виконуваний файл
Запустіть **`VoxFlow.exe`** або ярлик **`VoxFlow.lnk`** у кореневій папці проєкту.

### Збірка з вихідного коду (.NET 8+ SDK)
```powershell
dotnet build VoxFlow/VoxFlow.csproj -c Release
```

### Запуск автоматичних тестів
```powershell
./VoxFlow/bin/Release/net8.0-windows/VoxFlow.exe --self-test
```
